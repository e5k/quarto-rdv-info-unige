# Introduction to Quarto

This repository contains the material used during the presentation entitled *[Quarto: write, analyze, and publish in a single document](https://vie-de-campus.unige.ch/catalogue/P4563)* given in the context of the [Rendez-vous de l'info scientifique](https://vie-de-campus.unige.ch/catalogue/G96-RDVPUBLI) organised by the [Bibliothèque de l'Université de Genève](https://www.unige.ch/biblio/en/) on Nov 10, 2026.

## Content

- `quarto_rdv_info.*`: The presentation 
- `_quarto.yml`: The quarto configuration file
- `_template.yml`: The template configuration file
- `example1/`: Quarto project associated with the example "*One document, one output*" in the presentation
- `example2/`: Quarto project associated with the example "*One analysis, several outputs*" in the presentation
